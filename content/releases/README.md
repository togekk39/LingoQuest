# LingoQuest offline course 1.0.0

This branch hosts the original draft A1–A2 course for the offline LingoQuest app (version 1.2.0 or later).

Download `lingoquest-es419-enus-a1a2-1.0.0.lqp.json`, then choose Perfil → Contenido sin conexión → Importar paquete de curso. You may also paste the raw file URL into Descargar e instalar.

The 32 lessons, 320 learning exercises, challenge questions, 13 local challenge rules, 40 pronunciation text drills, placement questions and text missions work on-device. No account, cloud grading, speech API or sync service is used. This text package does not include prerecorded audio.

The content is original development material awaiting human editorial review. Local answers and scores support personal practice, not official ranking or certification. SHA-256 checks integrity; it is not an author signature.

Keep released version bytes immutable. For content changes, publish a new version. `catalog.json` in this branch points to the version branch; pin the Git commit SHA in download URLs for a fully immutable reference.
