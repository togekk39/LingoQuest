# Lesson Authoring Standard

[Español (Latinoamérica)](lesson-authoring-standard.es-419.md)

## Required lesson record

Use the lesson ID, unit and stop in the [master plan](curriculum-master-plan.md). Assign stable IDs to objectives, senses, prompts, prompt families, media and story references. Give each record an author, reviewer and content revision. Declare the relevant CEFR scales and paraphrase the selected descriptor as a measurable learner outcome. Choose a purpose, audience, situation and conditions, such as asking a host for a replacement and confirming the new time. State which prerequisite targets are necessary and how their absence can be addressed. Specify the four language-mode objectives and indicate interaction or mediation where a task actually elicits it.

Write natural en-US. Use everyday es-419 explanations and locally intelligible alternatives when a word varies by country, such as bus terms or names for everyday objects. Describe register and usage. Check omitted subjects, be agreement, do-support, adjective order, articles by sound, count/mass forms, tense/aspect, false friends, vowels, final consonants, and sentence stress when relevant. A contrast deserves a short specific example and a chance to practice. Use clear and varied reference voices over time. Evaluate intelligibility and communicative success with calibrated examples across accents. Preserve names, diacritics, identity and access options.

## Learning cycle

| Stage                   | Authoring and acceptance requirement                                                                                                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Goal                    | State one concrete outcome and show an example of when the learner needs it. Keep directions understandable at zero English and make supporting media optional when it is ancillary to the task.                                                                                                       |
| Vocabulary              | Record lemma or phrase, sense, inflections, es-419 gloss, natural bilingual example, and local media where relevant. Mark new or review. Introduce required language before testing it. Teach in short groups and offer optional additional exposure and examples in the same context.                 |
| Form and pattern        | Teach needed form, meaning and use. Mark the contextual gloss separately from assessed language. Contrast a frequent error in context. Include a spoken model and written example when applicable.                                                                                                     |
| Dialogue and input      | Show the purpose and participants. Include en-US audio and accessible transcript, translation or graded glossary. Audit the order of spoilers and provide translation as optional support in independent tasks. A reading or listening item must depend on the actual source.                          |
| Guided practice         | Move from recognition and understanding to recall and guided output. Include one meaning-focused comprehension check before the first unaided output. Record cue, hint, transcript, modeled answer, retries and task format.                                                                           |
| Independent application | Change the scenario, referent or information gap. An independent speaking activity must let the other speaker respond or follow up when interaction is the goal. An independent writing activity gives the learner an audience and a reason to write. Hide model answers until requested or submitted. |
| Assessment and review   | Attach key or rubric, feedback, conditions, delayed variants and an unfamiliar application. Use the local passing criteria in the master plan. Keep assessment records by mode and stage.                                                                                                              |

Record difficulty as a description of input length, speech rate, turn count, text density, familiarity, number of sources/constraints and available support. Build progression using those features. Start with short input and low memory load. By B1 include connected accounts with reasonable complexity. At B2 use multi-speaker discussion, longer arguments, contrasting texts and sustained output. Pilot with beginning readers, teenagers and adults where suitable. Add accessible reading support, scalable text, captions, keyboard/screen-reader labels and a local recording alternative or skip. Record an accommodation that changes the construct. A transcript can provide reading or supported comprehension evidence.

In unit review, budget guided and independent minutes by the primary language mode of each activity. Count an integrated task once for time and record each evidenced skill separately. Give Pre-A1 extra time for comprehensible listening and short spoken turns while building print and writing. From A1, require guided and independent opportunities for all four modes in every unit. From B1, preserve room for sustained speech and writing with feedback and for connected reading and listening. Report the unit mix, available independent tasks and missing evidence by mode, then adjust time allocations from observed learner performance.

## Keys, feedback and evidence

- For choices, check that exactly one option meets the prompt and key, alternatives are unambiguous, and timings, names, quantities, punctuation and answer order match across English, Spanish and media. For controlled replies, enumerate intended contractions, word-order and spelling variants that preserve meaning and form. Include positive and negative examples from the same prompt. Rejecting a natural equivalent without a meaningful criterion fails review.
- For open tasks, use an analytic rubric with task fulfillment, comprehensibility, the intended form or discourse strategy, and organization or interaction. Design independent prompts with samples from multiple valid strategies. Use human marking or transparent self-assessment offline until a method is validated. Keep self-assessment as practice. A valid alternate request can show meaning while leaving a grammar target unobserved. Explain that difference in feedback and give a usable next step.
- Explain one error directly in es-419, give a correct model and allow another attempt. Display the reason consistently in both entry points. When a correct answer is possible through a missing prerequisite, visible model or lucky guess, adjust the task or narrow the evidence.
- Record reading, listening, written output, spoken content and pronunciation or intelligibility as distinct observations. A typed answer to audio may supply listening/dictation evidence depending on the key. A typed answer without audio supplies no speech evidence. A recorded imitation is practice. Speech recognition can report a transcript; pronunciation requires calibrated human judgment or an audio method validated against it. For absent or unusable audio, mark the target unobserved and allow progress through an appropriate alternative.
- Calibrate with blinded samples and parallel forms. Report available evidence per mode, counts and delay, with error rates and abstentions by device and relevant learner groups. For individual learners, a practical result reads “understood the changed route in two independent checks, one delayed.” Show the oral status as unobserved if nobody has evaluated it. Story completion, challenge rank, XP and correct choices measure their own activities.

### Acceptance example · Locate a place

In `lq-home-plaza.place`, teach `Where is…?` and `It's next to…` with two landmarks. In the first guided map use a replay or phrase starter. In the immediate check use a different map with one location cue and no visible answer. Ask the learner to find the stop from audio and give a visitor a usable answer. Accept `The stop is beside the park` for the meaning task if `beside` is used correctly. Credit the specific `next to` target only if used. Check a library or other distinct setting after one day and later after about a week. Review the prompt, sound, both maps, marked key, assistance and resulting evidence before release.

## Acceptance gates

| Check                           | Automated gate and manual sign-off                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Order and vocabulary            | `npm run curriculum:verify` checks plan order, used prerequisite IDs, review-before-introduction errors, route coverage and EN/es-419 structural parity. The existing course validator checks textbook vocabulary and skill references. A reviewer walks each scenario in display order, marks required forms and senses, and reviews whether age, register and support make the task fair. |
| Exercise references and answers | Use current pack validation for IDs, stages, keys and assets. Verify correct-choice uniqueness, reorder token coverage and plausible accepted alternatives by item. A human checks semantics, feedback alignment and the interaction actually elicited.                                                                                                                                     |
| Offline integrity               | Run `npm run packs:verify` and `npm run packs:chapters -- --verify` in addition to the curriculum check. The curriculum checker detects drift between authored chapters, the bundled course, embedded units and the Home runtime. Test real playback, download, restart and airplane mode for a supported Android device and a production Web shell.                                        |
| Revision compatibility          | Run engine and backup tests. For each migration, load a previous version's progress, draft and scheduled review, then upgrade, retry the same attempt, reopen it and verify the state and review evidence after restore. Validate when a pack is missing or removed. Inspect any mapping with changed construct before granting credit.                                                     |
| Editorial review                | An en-US reviewer signs off language, task conditions and keys, and an es-419 reviewer signs off explanation, translation, register and feedback. Add accessibility and device checks and record qualified educator review of outcomes and level. Treat software tests as evidence of software behavior and use learner trials for teaching claims.                                         |
