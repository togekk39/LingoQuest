## Implementation and test contracts

- Source of truth is the existing `content/source` pipeline extended to canonical definitions. Keep chapter media revisions distinct from course semantics and persisted state. If `packages/course-pack` needs a schema change, keep old readers and immutable artifacts supported until a migration is proven. Move repetitive lesson configuration into validated data. Use existing offline engine scheduling and storage boundaries so both entry points share review decisions.
- On new authored lessons, validate assigned IDs, topological order, references by stage, strict required lexical/grammar tags, media with transcripts and transform boundaries between legacy and canonical evidence. For releases, compare prior and new registries. Every replaced ID needs an explicit retained, aliased, superseded or retired disposition. Retain old revisions needed by in-progress drafts, or offer an explicit safe resume/restart policy without loss of unrelated progress.
- Maintain fixtures for an old state, v2 import/export, partially answered chapter, pending review and earned challenge records. Verify monotonic upgrades, fail-safe transactions, download interrupt/retry and same attempt across channels. Reopen and restore after upgrade. Include plan vocabulary and grammar order, answer key/feedback consistency and packaging checks in the author's workflow. [Lesson Authoring Standard](lesson-authoring-standard.md)

## Scope of the next implementation PR

Keep the Android chapter-2 handoff and shared learning evidence at the top of the implementation queue. Preserve access to Home teaching and due reviews after switching or restoring a chapter, and connect the same early objectives through Story and direct Study with stable identities and idempotent, modality-specific evidence. Cover restart, airplane mode, old backups and retries before extending the architecture. Use the existing learner as a distinct character alongside Sam and Luz. Keep the main beginner flow untimed and non-penalizing, and retain the 13 challenge ranks as optional advanced practice. The present planning PR adds no runtime fix.

Bind annotations to the first shipped cross-entry teaching and exercise IDs and test parity with the presentation paths. Then trial compact Pre-A1 and A1 companion sets before commissioning the connected inputs, non-travel cases and independent performance tasks listed for later bands.
