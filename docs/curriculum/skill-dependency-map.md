# Skill Dependency Map

[Español (Latinoamérica)](skill-dependency-map.es-419.md)

The [master plan](curriculum-master-plan.md) lists directed edges for every lesson. An edge ending in `:form` requires understanding the named pattern. An edge ending in `:l`, `:s`, `:r` or `:w` requires the prior capability in that mode. Vocabulary in the Review column points to its first introduction by lexical entry. These are authoring dependencies and diagnostic targets. Study may reteach a missing prerequisite inline, recommend an earlier lesson or admit a learner after an appropriate independent sample. A learner can follow the associated story with support.

The target-specific edges on each lesson are authoritative. The stage depends on what the learner did. Read the complete prompt, key and supports before deciding whether practice built recognition, understanding, recall, production or transfer.

## What may share a learning record

| Observation                                   | Canonical targets and mode                                                                                                                               |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Select a greeting from text                   | Greeting recognition. Separate from exact recall of `hi` or `hello`.                                                                                     |
| Produce `My name is [chosen name]` in writing | Written introduction and the demonstrated template. Track shared communicative intent with `I'm [chosen name]`. Record the form actually used.           |
| Order the tokens in `It's next to the park`   | Guided form understanding. Keep independent direction giving as a separate observation.                                                                  |
| Hear a location and identify it on a new map  | Listening understanding. A viewed transcript changes the evidence to supported comprehension. An equivalent independent reading task belongs to reading. |
| Make and replay an introduction recording     | Oral practice. With a calibrated listener, score spontaneous spoken content and intelligibility on eligible audio using separate rubric dimensions.      |
| Summarize two sources accurately for a peer   | Attribute source facts in the observed spoken or written mode. Record mediation and interaction only when the prompt elicits them.                       |

## Delayed and novel practice

For each important lexical sense, form and communicative target, register teaching, supported practice, an independent opportunity and two delayed variants across settings. Start the queue roughly a day after first practice and again around day seven, then adapt using observed errors and the existing review intervals. A wrong unaided attempt can trigger explanation and a focused example before another unaided check. An assisted success can reinforce learning while its assistance stays recorded. A delayed replay of a previously exposed prompt demonstrates a different learning event from transfer to a genuinely new context. Use prompt-family IDs across entry points. Reopening a draft or changing its presentation does not create a new prompt family. Report status by mode and show evidence gaps where the relevant option or media is unavailable.

A stored legacy aggregate can seed a review invitation. It lacks the provenance necessary to award a new independent or delayed success. Keep durable IDs for current courses and skills. Use versioned mappings only when equivalence has been reviewed against the exercise, not merely its name.
