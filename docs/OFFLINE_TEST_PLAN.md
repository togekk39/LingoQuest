# 離線版驗收

2026-11-08：12 項 Playwright 情境全部通過（42.6 秒），測試期間沒有發出 `/v1/` 或未允許的外部請求。

瀏覽器測試只需要靜態網站服務，不啟動 Fastify，不使用登入、Supabase、OpenAI 或 Azure。每個案例從新的瀏覽器儲存空間開始，網路攔截器拒絕所有 `/v1/`、`/api/` 與未明確允許的外部請求。

測試範圍：

- 完整內建課程在飛航模式可直接判分、完成課程及記錄 XP，無待同步狀態。
- Service Worker 安裝後的離線冷啟動與進度持久化。
- 390px 手機導覽、五種練習輸入、40 組發音、可略過錄音、12 題診斷與機場任務。
- 瀏覽器只有遠端語音時，不呼叫語音合成。
- 13 級本機挑戰、獨立閱讀時間預算、失敗及退出不改變學習進度。
- 課程包從檔案離線匯入、有效更新保留進度、checksum 不符不取代原課程。
- GitHub 靜態內容下載只在使用者明確操作時發生；測試使用攔截的 HTTPS 發行檔，沒有呼叫 GitHub API。
- 本機資料備份、清除、還原，全程不需要帳號。

```bash
npm run build:web
npm run preview
# 另一個終端
npm run test:e2e
```

Node 單元測試另外驗證本機學習引擎及課程包的格式、SHA-256、大小與參照完整性。

瀏覽器測試不能替代 Android 真機飛航模式、錄音權限、儲存空間不足與文件選擇器驗收。Android 執行碼建置成功也不代表已產生或驗證簽章 APK。
