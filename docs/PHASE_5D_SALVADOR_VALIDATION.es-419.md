# Fase 5D-2D · Validación de Salvador

[English](PHASE_5D_SALVADOR_VALIDATION.md)

Sam y Luz llegan con la postal de Nora desde Cusco. La persona que juega ayuda a Jo y Rafa a preparar un almuerzo de intercambio y a otro equipo a montar una muestra de fotos. El último encuentro entrega el sello de Salvador y abre una postal para Valparaíso. El centro histórico de Salvador y Pelourinho dan contexto a la ciudad. La cocina y la sala son ilustraciones originales de lugares ficticios. El portugués es el idioma oficial de Brasil. El equipo usa el inglés para comunicarse. ## Coordinación del equipo

El encargo de Rafa se oculta hasta que una pregunta en inglés confirma el trabajo con la sopa. El tablero muestra tareas habituales, actuales visibles y confirmadas, disponibilidad y tareas pendientes o terminadas. Al confirmarse el encargo repetido, Jo termina de lavar y queda disponible. Puedes pedir que Sam corte el pan y Luz ponga los tazones, o que Jo corte el pan y Sam ponga los tazones. Alex descansa. Rafa sabe cortar el pan y está ocupado con la sopa. Los tazones dependen de que el pan esté listo. En la sala comunitaria hay que mover una mesa antes de colocar las etiquetas y hay otros voluntarios para cada tarea. [Definiciones de situación](../content/source/salvador-scenarios.ts)

Aceptar una petición requiere capacidad y disponibilidad y registra un acuerdo. Al avanzar, un evento de la historia inicia la tarea. Otro evento la termina. Las afirmaciones y las preguntas se evalúan según la tarea en curso. Si alguien recibe una petición repetida puede explicar quién ya tiene ese encargo. Una petición fallida, prematura o repetida conserva el tablero. La confirmación, las tareas, el borrador y la persona seleccionada se guardan en los puntos compartidos y respaldos. Las rutas de prueba comprueban dos repartos válidos, hechos que cambian, errores gramaticales, disponibilidad, dependencias y respuestas repetidas. [Analizador](../packages/offline-engine/src/team-language.ts) · [Transiciones](../packages/offline-engine/src/team-scenario.ts) · [Casos](../content/source/salvador-scenario-review.ts)

El motor distingue `target`, `communication_only`, `context_mismatch`, `incorrect` y `ungradable`. Comprueba las cláusulas admitidas completas, incluida la negación y la concordancia. Por ejemplo, `Jo’s washing the vegetables` demuestra la afirmación y la forma washing mientras la tarea está en curso. `Can Sam cut the bread?` consulta la capacidad. `Sam, can you cut the bread?` hace una petición. Si una frase abierta supera las formas admitidas, aparece una aclaración o una autoevaluación. El avance de la historia y la evidencia dependen del resultado correspondiente a la actividad.

## Repaso, retos y recursos sin conexión

El banco tiene guías y confirmaciones distintas para omitir be o elegir su forma, ortografía, rutinas, estados, orden de preguntas, negación, can + forma base, escucha de can y can’t, disponibilidad, estado de tareas y secuencia. Tras la guía, el error sigue pendiente hasta una respuesta independiente en otra situación. El repaso de texto archivado contiene los datos de la situación en el enunciado. Las correcciones de texto conservan la forma o el patrón evaluado al quitar el paquete. Para la escucha se requieren los archivos instalados. La transferencia del mismo día y la retención diferida tienen reglas distintas. Cada modo añade un reto por objetivo con requisitos revisados y práctica independiente correspondiente. Ejecuta `npm run curriculum:verify`, `npm run packs:verify`, `npm run packs:chapters -- --verify`, `npm run check`, `npm test`, `npm run build:web`, `npm run test:e2e`, `npm run build:android` y `npm run build:apk`. Verifica los flujos del commit candidato y el APK firmado. La regresión del motor usa el paquete publicado para comprobar la enseñanza, los turnos guardados, ambos repartos, el refuerzo de ortografía, los requisitos de los retos y el repaso diferido. La regresión del navegador usa Enter, audio instalado, navegación sin conexión, Historia y Estudio, reinicio, respaldo, pasaporte y actualización desde la ficha de Brasil.
