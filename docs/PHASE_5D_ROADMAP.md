# Phase 5D Curriculum Roadmap

[Español (Latinoamérica)](PHASE_5D_ROADMAP.es-419.md)

Phase 5D starts from `cf1b763`, the merge of Phase 5C into `main`. The catalog at that commit has 20 downloadable chapter cards. The first eight packs also include the 32 published Study lessons. Home is the only fully implemented RPG at that baseline. Phase 5D covers the 24 planned units and 83 objectives across the existing route. The current milestone is the Phase 5D-1 Mexico City correction. Develop and review each chapter before beginning formal content for the next chapter. For each chapter, record source and translation checks, instructional prerequisites, accepted and rejected answers, audio and art coverage, story continuity, modality coverage, alternate assessments, remediation and optional challenge gates. Reuse canonical learning IDs, keep independent evidence distinct from practice and self-checks, and check pause/resume, versioned offline install and prior progress.
