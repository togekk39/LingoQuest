# Local API

This is the working local development backend. It uses Node 24 `node:sqlite`, durable local accounts and signed, revocable JWT sessions. The hosted Supabase adapter is not configured. All original content remains a development draft; ranked runs are intentionally unavailable. All 13 levels of the present-simple practice track are playable, including grammar, cloze and reading. Later tracks are previews.

Run from the repository root: `npm run dev:api`. Default address: `http://localhost:3001`. `PORT=3000 npm start -w @lingoquest/api` also serves the exported `apps/mobile/dist` bundle if present. No provider credentials or paid API calls are required.

Environment: `PORT` (3001), `HOST` (0.0.0.0), `DATABASE_PATH` (`data/lingoquest.sqlite` relative to the process directory), `SESSION_SECRET` (optional strong external secret; otherwise generated once in the local database), `CORS_ORIGINS` (comma-separated explicit origins; development default reflects origins). Configure explicit origins and TLS before external use. General rate limit is 300 requests/minute/IP; account registration/login is 15/minute/IP; guest creation is 20/minute/IP.

Every authenticated endpoint requires `Authorization: Bearer <token>`. Client user IDs, scores, heart counts and deadlines are never accepted. JSON request schemas reject extra fields. JWT signature, fixed issuer/audience, expiry, stored session and user ownership are checked server-side.

`answer` has exactly one of `{optionId:string}`, `{text:string}`, `{tokens:string[]}`. Request IDs are 8–100 characters; UUIDs are recommended. Reusing an ID with different input returns 409. Required lesson steps are satisfied by an attempted answer, including an incorrect one; repeated errors do not block lesson completion. Each lesson grants 25 XP once. Daily exercise evidence and delayed-review rewards are deduplicated independently of request IDs. A first recognition answer cannot establish long-term mastery.

Practice runs retain private answer/config snapshots, use server-authoritative clock and heart deduction, and persist results separately from learning. Relaxed practice has no deadline. Practice never awards ranked badges or alters learning XP, mastery or lesson completion. Reading/cloze use independent passage-based clocks. Drafts cannot enter the ranked state machine, regardless of client fields or unit completion.

The SQLite local user ownership checks are exercised by API integration tests. Supabase RLS migrations and PostgreSQL tests are separate production preparation; this local API does not claim to operate a hosted PostgreSQL deployment or human-reviewed production curriculum.
